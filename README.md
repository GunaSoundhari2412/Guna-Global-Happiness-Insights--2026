# Global Happiness Insights Dashboard

A Data Science project focused on analyzing global happiness trends using data cleaning, visualization, and interactive dashboard techniques.

---

## Project Overview

The Global Happiness Insights Dashboard is designed to analyze the World Happiness Report dataset and identify the major factors that influence happiness levels across different countries.

This project demonstrates the complete Data Science workflow, including data preprocessing, missing value handling, duplicate removal, exploratory data analysis, data visualization, and dashboard development using Streamlit.

---

### Objectives

- Analyze global happiness data.
- Clean and preprocess real-world datasets.
- Handle missing values and duplicate records.
- Identify relationships between happiness and socio-economic factors.
- Create meaningful visualizations.
- Develop an interactive Streamlit dashboard.

---

### Features

-  Data Cleaning and Preprocessing
-  Missing Value Detection and Handling
-  Duplicate Record Removal
-  Exploratory Data Analysis (EDA)
-  Data Visualization using Matplotlib and Seaborn
-  Correlation Analysis
-  Interactive Dashboard using Streamlit
